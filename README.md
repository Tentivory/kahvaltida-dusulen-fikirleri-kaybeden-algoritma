# Kahvaltıda Düşülen Fikirleri Kaybeden Algoritma

## Dünyanın En Devrimci (ve En Gereksiz) Buluşu

Bu proje, insanlık tarihinin en büyük sorununu çözmek için yaratılmıştır: **Kahvaltıda aklına gelen o muhteşem fikirlerin, daha çay bitmeden unutulması.**

Artık endişelenmenize gerek yok. Algoritmamız bu işi sizin yerinize, profesyonelce ve geri dönüşsüz olarak halleder.

### Nasıl Çalışır?

1. Kahvaltı masasında otururken aklınıza gelen o "dünyayı değiştirecek" fikri yazın.
2. Programı çalıştırın.
3. Fikir, yumurta, peynir ve zeytin arasında bilimsel olarak kaybolur.
4. Siz sadece çayınızı içmeye devam edin.

### Kurulum ve Kullanım

```bash
python fikir_kaybedici.py
```

Başka hiçbir şey yapmanıza gerek yok. Algoritma kendi kendine çalışır. Hatta siz uyurken bile fikirlerinizi kaybedebilir (gelecek versiyonlarda).

### Bilimsel Kanıtlar

- %99.7 başarı oranı (geri kalan %0.3'te fikir zaten kötüydü).
- Kahvaltı öncesi ve sonrası beyin taramaları ile doğrulanmıştır (uydurma tarama).
- Nobel Ödülü komitesine başvuru yapılmıştır (henüz cevap gelmedi, muhtemelen kahvaltıdasınlardır).

### Katkıda Bulunma

Pull request açabilirsiniz ama açtığınız anda fikirleriniz kaybolabilir. Risk size ait.

### Lisans

MIT Lisansı. Ama fikirleriniz bizimdir. Hayır, kayboldu zaten.
